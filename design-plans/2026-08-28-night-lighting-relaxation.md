# 야간 추천 조명 기준 완화

사용자 요청: 가로등이 적당히 있는 코스도 추천하도록 기존 기준을 낮춘다.

- 야간 최소 점수를 0.60 → 0.33으로 변경한다. 기존 화면의 어두움 범위는
  0.32 이하이고, 저장된 서울 표본의 중앙값은 0.33이다. 이는 앱 데이터의
  추천 필터이며 실제 조도나 현장 안전 기준을 뜻하지 않는다.
- ‘조명 좋음’ 표시는 여전히 0.60 이상이다. 0.33~0.59에 해당하는 코스는
  ‘야간 조명 보통’으로 표현한다. 배지, 상세 설명, Markdown을 동일하게 맞춘다.
- 기본값 0.5만 있는 경로를 실제 조명 데이터로 착각하지 않는다. 경로 요약에
  관측 근거가 있는 길이 비율을 기록하고, 관측이 전혀 없으면 제외한다.
  구형 요약의 0.5도 관측 근거가 없으면 보수적으로 제외한다.
- 보통 조명으로 통과한 코스에 ‘선택 특징 미충족’이 붙지 않도록 순위 판단도
  같은 기준을 사용한다. CCTV는 경로 가중치로만 유지하고 필수 할당량은 두지 않는다.
- 한 번 호출로 서로 다른 3개를 반환하는 계약과 출발지 조건은 유지한다.
  실제 조명·경로 후보가 부족하면 실패할 수 있으며, 그때 경로를 꾸며 내지 않는다.

실측한 등록 공원 경로 점수: 여의도 0.47, 반포 0.76, 뚝섬 0.63,
서울숲 0.80, 양재천 0.34. 새 기준으로 다섯 곳 모두 야간 후보가 된다.
특히 강남역 기준 공원 야간 추천에 양재천이 다시 포함되는 것을 회귀 테스트한다.

일반 코스의 지역별 샘플에서는 서울시청·서울역이 3개를 반환했지만,
강남역·봉천역은 조명 기준에 맞는 일반 코스를 확보하지 못했고 홍대는
서로 다른 후보 수가 부족했다. 기준 완화가 모든 지역의 성공을 보장하지 않는다.
이 기록은 로컬 데이터/서버 검증이며 카카오 배포 반영을 뜻하지 않는다.

검증: 관련 테스트 159개 통과. 전체 회귀 테스트 481개 통과(103.11초),
이미 기록된 프로세스 풀 미사용 시 고래 생성 타임아웃 테스트 1개만 제외했다.
등록 공원 5곳의 현재 실제 점수와 ‘보통/양호’ 표시도 직접 확인했다.

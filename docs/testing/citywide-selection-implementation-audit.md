## 명확히 한 예외

- 무출발지 공원 추천은 기존 동작을 보존한다. 구를 지정하면 등록 목적지의 구로 제한한다.
- `park`는 여기서 **공원/수변 목적지 모드**다. 실제 데이터에서 등록 5개 경로 모두 10m 내 `park` POI는 0개다. 따라서 공원 자체는 기존 검증(실제 보행 경로·공원 비중 ≥0.9)으로 확인하고, 추가 화장실·편의점·음수대만 POI 10m 필터를 적용한다. 이 해석은 공원 예외 보존 결정에 따른다.
- 일반 코스의 2·3번에는 다른 모양이 표시된 동물 프리셋이 섞일 수 있다. 1번은 항상 실제 일반 코스이며 명시 거리·지형·시설 조건은 대안에도 그대로 적용된다.
- 구 전체 경로가 구 경계 안에 있다고 보장하지 않는다. 보장하는 것은 **해당 구에 속한 출발지**다. 역은 번들 주소, 공원은 등록 목적지 구를 근거로 한다.
- 일반 구 추천은 역 하나에서만 생성한다. 실패 후 다른 역·다른 구로 자동 재시도하지 않는다.
- 공원 무출발지 랜덤 선택은 예외로 유지하며, 구별 선정·특정 위치 선정은 무작위 선택을 쓰지 않는다.

## Blockers

- 운영 배포·PlayMCP 수정은 수행하지 않았다. 커밋·푸시와 운영 승격은 별개이며, 미커밋 상태로 만든 로컬 검증 이미지 대신 실제 배포할 커밋 SHA로 새 이미지를 빌드해야 한다.
- 실제 Kakao Tools Preview의 새 대화 발화/위젯 렌더링/재등록 스키마 확인은 미완료다. 로컬 JSON Text 존재 검사는 호스트 렌더링 증거가 아니다.
- 일반 코스 평균이 로컬에서도 100ms를 초과한다. 운영과 같은 CPU·메모리·동시성에서 실제 MCP HTTP 부하 측정 및 기준 충족 확인이 필요하다.
- 저장소에 추적된 CI workflow/의존성 lock이 없고 원격 CI 실행 상태는 확인하지 않았다.
- 로컬에 Kakao REST/JavaScript 키, 토큰 서명키, 법적 문의 이메일이 없다. 외부 주소 검색·실제 지도 SDK·운영 토큰 설정은 확인하지 않았다. 단, 새 코스 추천은 토큰 키 없이 정상 동작한다.
- 직전 운영 이미지 digest와 실제 툴 스키마 백업이 제공되지 않았다. README에 롤백 순서는 추가했으나 실제 복귀 실행은 미검증이다.

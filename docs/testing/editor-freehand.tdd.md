# 그린 대로 따라가는 코스 편집 — TDD 증거

2026-08-30. 계획: `~/.claude/plans/https-preview-chatgpt-kakao-com-nested-frost.md`

## 사용자 여정

- 자유롭게 그린 선이 **그린 모양 그대로** 옆 보행로에 맞춰 코스가 된다. 최단 경로가 아니다.
- 지우개로 지운 구간은 실제로 사라진다. 왕복(spur)이면 그릴 것도 없이 그대로 닫힌다.
- 저장되는 코스 = **남은 초록선 + 그린 파란선**. 지우개를 썼든 안 썼든 규칙은 하나다.

## 원인

측정으로 고정한 두 가지다.

1. **`stroke_waypoints()`가 그림을 지웠다.** RDP 단순화를 stroke 전체의 현(chord) 기준 45m로
   먼저 돌렸다. 부드러운 곡선은 깊이와 무관하게 자기 현으로 붕괴한다 — 1,017m 구간 위의
   **179m 깊이 곡선 61점이 경유점 1개**가 되었고, 남은 두 점 사이는 전체 그래프 최단경로로
   이어졌다. 결과: 코스 길이 **+11m**, 그린 선에서 평균 이탈 **83m**.
2. **지우기가 지우지 않았다.** `snap_drawn_strokes()`는 stroke가 비면 즉시 거부했다.
   `path[lo] == path[hi]`인 완전한 왕복(지우면 그대로 닫히는 경우)까지 거부해, 존재할 수 없는
   선을 그리라고 요구했다. 왕복을 잘라내는 `collapse_excursion()`은 있었지만 클라이언트가
   절대 보내지 않는 `reroute` 액션에만 연결돼 있었다.

## 구현

`_densify`(20m) → `_smooth`(boxcar 160m) → `_resample_by_arc`(130m) → **코리도 제약 Dijkstra**
(그린 선 주변 70m 튜브, 실패 시 110/170m로 확장, 그래도 안 되면 해당 hop만 전체 그래프 구제).

RDP는 제거했다. 손떨림(고주파·평균 0)과 의도한 굴곡(저주파·지속)을 가르는 것은 **호 길이
기준 이동평균**이지 현 기준 단순화가 아니다.

접합은 **노드 id가 아니라 인덱스**로 한다. 폐곡선은 같은 노드 id가 두 지점을 가리키므로
id 매칭이 한쪽만 닿은 선을 루프 반대편으로 splice했고, 거리 검사가 우연히 막고 있었다.

## 캘리브레이션 노브

`STROKE_SMOOTH_WINDOW_M`가 이 기능의 유일한 노브다. 측정된 사용 가능 대역은 **140~200m**.

- 140m 미만: 떨림이 경로를 조종한다(100m에서 배터리 5.87x — 대체 대상보다 나쁘다).
- 200m 초과: 의도가 사라진다(300m에서 그린 180m 곡선이 135m로 축소).
- 140m 이상에서는 곡선이 평평하다. 앵커 간격(130m)이 이미 이웃 샘플을 탈상관시키기 때문이다.

재튜닝은 취향이 아니라 위 배터리를 다시 돌려서 한다. 상수의 기본값은 대역 중앙인 160m다.

`_densify`/`_smooth`는 기본 인자가 아니라 **본문에서 상수를 읽는다**. 기본 인자는 import 시점에
바인딩되어 노브를 얼어붙게 하고, 노브를 쓸어보는 테스트가 아무것도 측정하지 않으면서
통과한다 — 실제로 첫 구현에서 그렇게 되어 잘못된 대역을 결론냈다.

## 발견해서 함께 고친 것

- `applySummary()`가 형태가 어긋난 summary에 대해 중간에 예외를 던져 **호출자의 경로 갱신까지
  같이 날렸다**. 패널은 장식이고 경로는 아니므로 맨 앞에서 조기 반환하도록 했다(모든 호출자에
  한 줄로 적용).
- `collapse_excursion()`은 200 인덱스를 탐색한다. 지우개가 넘기던 짧은 구간에는 맞지만 긴
  sweep에는 너무 자유로워, 5km 루프를 1km 미만으로 잘랐다. 지운 구간 길이 + 250m 상한을 걸었다.
- 접합 후보를 "초록을 가장 적게 지우는 순"으로 정렬하면, 지운 구간이 없을 때 **아무것도 지우지
  않는 쌍**이 이겨서 그린 선이 코스 옆에 덧붙는다(5.2km → 6.2km). 근접순으로 바꾸고 붕괴 방지는
  삭제량 상한에 맡겼다. 이제 지우개를 쓴 결과와 안 쓴 결과가 **완전히 일치**한다(둘 다 5.26km).
- 죽은 코드 제거: `_snap_tips_to_retained`, `DRAW_TIP_JOIN_MAX_M`(`7fb669e`가 호출부만 지움),
  `_bridge_drawing_to_retained`, `_connect_through`, `_simplify`.
